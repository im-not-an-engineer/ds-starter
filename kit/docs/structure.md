# 구조 — 에이전트가 이 시스템을 읽는 법

## 에이전트의 흐름

```
ds.config.yaml (무엇을 위한 · 대상 · 구현 방식) + 지침 지도(design/map.yaml) + 읽는 법(reading.md)
   │
   ├─ 판단 세션: 요청 → 업무 → 사실 확인 → 화면 유형 고르기(fits · avoid, 없으면 P-free)
   │        읽는 것: 화면 유형 · 사실 · 갈림 · 업무 · 상태 문법 · 규칙 · 그림 · 컴포넌트 목록
   │        └ decision.md
   │
   └─ 그리기 세션: 골격(HTML)에서 출발 → 자리를 컴포넌트로 채움 → 상태마다 한 장
            읽는 것: 고른 화면 유형과 골격 · 어휘 · 컴포넌트 계약 전체 · 구성 · 문구 · 상태 · 플랫폼 문법 · 갈림 · 규칙 · 그림
                    │
              검사 — 계약(없는 클래스 · 엉뚱한 변형 · 짜임 밖 · 한 prop 에 값 둘 · 빠진 속성) · 직접 준 스타일 · 규칙 · 문법의 check
                    │
              notes.md — 짐작한 것 → 품질 루프가 구조로 채운다
```

## 층

| 층 | 원천 | 에이전트가 얻는 것 |
|---|---|---|
| 값 | `tokens/` — 재질 · 계약 · 모드, 갈래마다 고르는 법 | 계약 이름과 뜻 · 언제 · 쓰지 않을 때 · 짝. 컴포넌트 CSS 만 쓴다 — 생성 화면은 클래스로만 |
| 어휘 | `vocabulary.yaml` | 강도 · 크기 · 뜻 색 · 면의 세기 — 모든 컴포넌트에서 같은 이름 |
| 컴포넌트 | `components/` · `layout/` — spec.yaml + style.css · behavior.js | 클래스 · props(변형) · 상태(속성) · 짜임 · 언제 · 쓰지 않을 때 · 접근성. 동작은 HTML 참조 구현이 |
| 문법 | `grammar/` — 구성 · 문구 · 상태 · 플랫폼 | 위계 · 간격 리듬 · 정렬 · 밀도 · 강조 · 말투 · 표기 · 상태 처리 |
| 판단 | `judge/` · `layouts/` — 화면 유형 · 사실 · 갈림 · 업무 | 무엇을 고르나와 출발할 HTML 골격 |
| 규칙 | `rules/` | 늘 지킬 것 — grade(바꿀 수 있는 범위) · check |
| 그림 | `images/` | 이 시스템의 모양 · 밀도(배울 것) |
| 구현 | `implementation.yaml` | 계약 → 개발 컴포넌트(사람 · 개발 에이전트가 읽는다) |

## 고정된 것과 고치는 것

- **고정(스타터킷):** 도구가 아는 네 종류(tokens · components · images · guidance), 컴포넌트 계약의 칸, 값의 뜻 칸, 작업과 선행 조건.
- **보편 기준(깔고 고친다):** 계약 키 97 · 어휘 4 · 컴포넌트 24(+ 프로필) · 문법 · 화면 유형 10 · 사실 7 · 갈림 6 · 규칙.
- **이 시스템의 것(채운다):** 값 · 모양(피그마) · 기준 화면 · 업무 · 이 제품의 선택.

프로필(`ds.config.yaml` 의 profile)이 더하는 것:

| | 모바일 앱 | 모바일 웹 | 데스크톱 웹 |
|---|---|---|---|
| 컴포넌트 | 상단 바 · 하단 탭 바 · 바텀시트 | 모바일 앱과 같음 | 앱 틀(사이드바) · 표 · 도구 줄 · 쪽 넘김 |
| 골격 | 큰 제목 상단 바 · 아래 고정 행동 · 탭 바 | 같음 | 앱 틀 + 판 머리 · 도구 줄 · 표 |
| 문법 · 규칙 | 내비게이션 · 엄지 · 눌림 자리 · 한 줄 | + 링크 · 브라우저 높이 | 앱 틀과 판 · 조밀 · 읽는 폭 · 키보드 |

## 검사가 보는 것

| 원천 (`npm run check`) | 생성 화면 (`npm run ds -- check <파일>`) |
|---|---|
| 지도 · 원천 모양, 지도에 없는 칸(오타), 꼭 있을 칸 | 없는 클래스 |
| 값: 참조 · 순환 · 모드 키 · 짝 · **뜻 없는 값** | 변형이 그 컴포넌트에 없는데 붙음 · 한 prop 에 값 둘 |
| 컴포넌트: CSS ↔ spec · 계약 밖 값 · 직접 적은 색 · 어휘 밖 이름 · 그림 파일 · 예시의 계약 | 짜임 클래스가 그 컴포넌트 밖에 |
| 화면 유형의 골격 HTML 의 계약 | 빠진 속성(아이콘만 버튼의 aria-label 등) |
| 끊긴 `[[ID]]` · ID 중복 | `style=""` · `<style>` |
| 구현 대응표의 빈 곳(구현 방식을 정했을 때) | 규칙 · 문법의 check(조건 when-class · unless-class) |
