# 참고 사례 — 한 데스크톱 업무 시스템이 이 구조를 어떻게 썼나

이 스타터킷은 한 데스크톱 업무용 웹 제품의 디자인 시스템(이하 「참고 사례」)에서 LLM 이 화면을 만드는 흐름만 떼어 낸 것이다.
**구조를 따라 하라는 글이 아니다.** 한 시스템이 여섯 칸을 어떻게 채웠고, 무엇을 배웠는지를 적는다. 목적이 다르면 다르게 나눈다.

## 여섯 칸을 이렇게 채웠다

| 칸 | 참고 사례의 묶음 | 규모(대략) |
|---|---|---|
| 읽는 법 | 마크업 규약 · 고르는 순서(흐름 → 화면 유형 → 뷰 → 정책 → 자리 · 상태 · 문구 → 기록) · 어긋날 때의 등급 | 한 쪽 |
| 값 | 재질 → 계약 2층, 라이트 · 다크. 장식색은 번호로(`decorative.1`) — 색 이름을 넣으면 브랜드가 바뀐 순간 이름이 거짓말이 된다 | 계약 220여 개 |
| 부품 | 부품(spec 이 원천) · 컴포짓(부품을 늘어놓은 조립) · 블록(다 채워진 화면 예시) | 부품 70여 · 컴포짓 · 블록 |
| 그림 | 키스크린(화면 유형마다) | 50여 장 |
| 판단 | 화면 유형(주된 일로 고름) · 뷰(하는 일 × 데이터 모양) · 정책(동작 방식, 기본값과 선택지) · 사실(고르기 전에 물을 것) · 선례 | 각 수십 |
| 검사 | 규칙(심각도 · 등급 · 기계 검사) · 계약 린트 · 지침 누락 검사 | 규칙 수십 |

## 배운 것

1. **값 · 부품 · 검사는 LLM 이 지키게 할 수 있다.** 값 파일만 줘도 계약 밖 값은 거의 나오지 않았다. 규칙의 실제 역할은 값 지키기가 아니라 **상태와 구조의 누락을 막는 것**이었다.
2. **결과를 바꾼 것은 일반 원칙이 아니라 제품의 선택(기본값)이었다.** 「좋은 화면은 …」 같은 원칙은 결과를 거의 바꾸지 않았다. LLM 이 남긴 「확인 필요」 60여 개가 곧 제품이 정해야 할 선택의 목록이었다.
3. **부품이 모자라면 LLM 은 묻지 않고 지어낸다** — 또는 부품 파일을 직접 고친다. 그래서 판단 항목(패턴)은 부품으로 실현할 수 있는 것만 둔다. 패턴 목록이 부품보다 크면 없는 부품을 지어낸다.
4. **재료를 끝없이 늘릴 수 없다.** 뷰가 열 개면 고르는 기준이 선명하지만 서른 개면 「표 A 인가 표 B 인가」 가 된다. 재료의 양과 선택의 명확성은 서로 당긴다.
5. **층을 줄였다.** 한때 재질과 계약 사이에 「역할 램프」 층이 있었는데, 실제로 필요한 것은 거의 다 이름표 재배정이었고 한 칸의 혼란(「어디를 고쳐야 하지?」)만 남아 걷어냈다. 결과 값은 한 글자도 바뀌지 않았다.
6. **지침 총량은 제한하지 않되, 작업마다 필요한 것만 묶는다.** 판단 세션과 그리기 세션에 다른 묶음을 주고, 어떤 지침이 전달됐는지 기록(전달 기록)을 남겼다.
7. **생성 시험은 짓는 사람과 떨어진 곳에서.** 설계한 사람이 같은 세션에서 시험하면 결과가 오염됐다.

## 스타터킷에 그대로 옮긴 것 · 바꾼 것

| 참고 사례 | 스타터킷 |
|---|---|
| 지침 지도(`guide.yaml`) — 묶음을 선언하면 도구가 지도만 보고 팩을 만든다 | 그대로(`design/map.yaml`). 칸을 줄였다 |
| 판단 / 그리기 세션별 지침 묶음 · 전달 기록 | 그대로(`ds context`) |
| 컴포넌트: spec(props · states · anatomy · 결정) + React 구현(헤드리스 Base UI) | **같은 계약 형식 + HTML 참조 구현.** 구현 방식(HTML · 헤드리스 · 오픈소스 · 기존 코드)은 고른다 |
| 토큰 2층 · 어휘(vocabulary) · 유틸리티의 고르는 법 | 그대로 — 계약 값마다 뜻 · 언제 · 쓰지 않을 때 · 짝, 갈래마다 고르는 법 |
| 화면 유형 · 뷰 · 정책 · 사실 · 선례 · 골격(layouts) | **보편 기준으로 미리 깐다** — 화면 유형 10과 골격 · 사실 · 갈림 · 업무(빈 칸). 프로필이 대상별 골격을 바꾼다 |
| 샌드박스(OpenAI API · 뷰어) · 미리보기 서비스 · 발행 파이프라인 | 생성 세션(서브에이전트) + 파일 하나짜리 미리보기. 발행은 아직 없다 |
